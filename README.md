# Monte Carlo Portfolio Simulation

## Project Overview

This project uses Monte Carlo simulation to model possible future portfolio values under uncertainty.

The simulation generates multiple random portfolio paths based on assumed return and volatility parameters to estimate potential future outcomes and downside risk.

---

## Features

- Monte Carlo portfolio simulation
- Portfolio return path visualization
- Value-at-Risk (VaR)
- Conditional Value-at-Risk (CVaR)
- Risk distribution analysis

---

## Technologies Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Key Risk Metrics

### Value-at-Risk (VaR)

VaR estimates the maximum expected portfolio loss over a given confidence level.

### Conditional Value-at-Risk (CVaR)

CVaR measures the expected loss beyond the VaR threshold under extreme downside scenarios.

---

## Result

The simulation generated multiple possible portfolio paths and visualized uncertainty under different market conditions.
