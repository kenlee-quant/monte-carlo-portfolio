# Interview Notes

## Project Explanation

This project uses Monte Carlo simulation to model possible future portfolio values under uncertainty.

I simulated many possible return paths using random variables based on expected return and volatility assumptions.

The goal was to estimate downside risk and understand the probabilistic behavior of portfolio performance.

---

## Key Concepts

### Monte Carlo Simulation

A method used to model uncertainty through repeated random sampling.

### Value-at-Risk (VaR)

Measures potential portfolio loss under a confidence interval.

### Conditional Value-at-Risk (CVaR)

Measures expected loss beyond the VaR threshold during extreme downside events.
